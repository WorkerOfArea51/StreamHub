# About Suite (`ui/screens/about`)

The `about` package encapsulates StreamHub's official branding, architecture overview, runtime diagnostics, and community links.

---

## Architecture & Modular Breakdown

| File | Purpose |
| :--- | :--- |
| `AboutComponents.kt` | Reusable UI rows (`FeatureHighlightRow`, `ExternalLinkRow`) and official community URL endpoints. |
| `AboutScreen.kt` | The master About screen displaying brand logo, architecture highlights, ARM64 build info, Telegram bot link, and open source licensing. |
